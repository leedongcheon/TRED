# TRED

**Execution-Grounded Hindsight Self-Distillation for Temporal Knowledge Graph Question Answering**

Official implementation of **TRED** (Temporal Reasoning learned via Execution-grounded hindsight self-Distillation), a framework for temporal knowledge graph question answering (TKGQA).

## Overview

TRED enables an LLM agent to perform multi-step temporal reasoning through executable operations over temporal knowledge graphs. A symbolic executor maintains intermediate results and variable dependencies, allowing TRED to construct **Execution Hindsight** that identifies answer loss and traces relevant preceding decisions.

An analyzer transforms this evidence into episode-level and decision-level hindsight skills, which guide on-policy self-distillation without treating proposed corrections as ground-truth actions.

TRED is trained in three stages:

| Stage | Description |
|---|---|
| **1. Temporal-Operation SFT** | Initialize the actor with successful executable trajectories generated by a teacher LLM. |
| **2. Hindsight-Skill SFT** | Train the shared actor–analyzer model using execution-grounded hindsight and verified correction guidance. |
| **3. Self-Evolving On-Policy Distillation** | Jointly optimize outcome-based RL and hindsight-guided distillation using trajectories and skills generated by the current policy. |

At inference, only the actor and symbolic executor are required.

## Setup

**Requirements:** Python 3.12, CUDA 12, and compatible NVIDIA GPUs.

```bash
conda create -n tred python=3.12 -y
conda activate tred
pip install -r requirements.txt
pip install flash-attn==2.8.3 --no-build-isolation
```

Configure the repository-level `.env` file:

```bash
CUDA_VISIBLE_DEVICES=0,1
BASE_MODEL=Qwen/Qwen2.5-3B-Instruct

OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-4.1-mini
```

The base model and BGE-M3 encoder are downloaded from Hugging Face when first used.

## Datasets

TRED supports **MultiTQ** and **TimelineCronQR**.

Place the corresponding KG and question files under:

```text
datasets/
├── MultiTQ/
│   ├── kg/
│   └── questions/
└── TimelineCronQR/
    ├── kg/
    └── questions/
```

Dataset split IDs are provided under `data/tkgqa/splits/`.

Prepare each dataset using:

```bash
DATASET=MultiTQ bash scripts/data/prepare.sh
DATASET=TimelineCronQR bash scripts/data/prepare.sh
```

## Training

Run the three training stages sequentially:

```bash
# Stage 1: Temporal-Operation SFT
DATASET=MultiTQ bash scripts/stage1/run.sh

# Stage 2: Hindsight-Skill SFT
DATASET=MultiTQ bash scripts/stage2/run.sh

# Stage 3: Self-Evolving On-Policy Distillation
DATASET=MultiTQ ARM=tred bash scripts/stage3/run.sh
```

For TimelineCronQR, replace `DATASET=MultiTQ` with `DATASET=TimelineCronQR`.

To train the outcome-only GRPO baseline:

```bash
DATASET=MultiTQ ARM=grpo bash scripts/stage3/run.sh
```

Alternatively, run the complete pipeline, including data preparation and evaluation:

```bash
DATASET=MultiTQ bash scripts/run_tred.sh
```

## Evaluation

Evaluate the trained checkpoints using:

```bash
DATASET=MultiTQ bash scripts/eval/run.sh
```

To evaluate a specific checkpoint:

```bash
DATASET=MultiTQ bash scripts/eval/run.sh NAME=<checkpoint_path>
```

Evaluation reports **Exact Match (EM)**, **Hits@1**, and **answer-set F1**.

## Repository Structure

```text
tkgqa/          Temporal KG, symbolic executor, and execution hindsight
seed/           Hindsight analyzer and skill prompting
agent_system/   TKGQA agent environment and interaction history
verl/, gigpo/   RL and SFT training frameworks
scripts/        Data preparation, training, and evaluation scripts
data/           Dataset splits and auxiliary files
```

## Reproducibility

Stages 1 and 2 use GPT-4.1-mini for teacher-generated trajectories and hindsight skills. Regenerated data may differ from the original experiments due to API model variability.

Training scripts support resuming from existing intermediate outputs. Experimental hyperparameters and evaluation protocols are described in the paper.
